TuneLab v0.18

Extract the complete ZIP. Double-click Start-TuneLab.bat for an Edge/Chrome app-style window. Use Open-TuneLab-in-Browser.bat for a normal browser, or open portable/index.html directly. If your computer blocks the PowerShell launcher, the direct HTML route remains available.

Before changing release folders or browser profiles, Save Project from your existing workspace. Use Open Project here to restore it. Browser caches are specific to their profile/folder.

Use UAT-v0.18.html for nine exact-navigation tests. docs/fixtures/V0.18-current.json and V0.18-saved.json are disposable synthetic fixtures, not vehicle tunes. Read docs/V0.18-SCOPE.md for restore scope and undo limits. No live ECU action is supported.
