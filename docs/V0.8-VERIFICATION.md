## Important distinctions

Boost and gear links locate recorded operating inputs; they do not establish ECU control influence or calibration match. Missing atmospheric pressure uses a labeled user reference. Logged command is only a candidate Command-index coordinate. Out-of-axis locations do not extrapolate.

AFM links use the analysis engine’s eligible observations; local support is actual Hz within bandwidth, while kernel membership uses the same 50 Hz bin centers and configured radius as the engine. Counts are coverage, not confidence. Display filters do not recalculate proposals. Validation does not drive correction. Saved/manual-only proposals lack fresh analysis provenance.

The AFM button previously captured the original function, bypassing later workflow wrappers. It now resolves the current analysis function, enabling existing per-export normalization and the new provenance record. No engine calculation formulas changed.
