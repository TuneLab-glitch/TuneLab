# v0.16.1 Selected Table Workbook Export

Adds Export Excel Workbook in the top header. Recommended pairs current proposals with source tables; on Boost By Gear it includes the current displayed gear layout. Select All Available and Clear Selection are provided. Stale/unavailable proposals are disabled. Source and proposal MPR/Command/AFM tables and displayed gear tables are supported. Each KTuner gear becomes a separate sheet; Hondata retains RPM rows and gear columns. Evidence charts, raw logs and arbitrary custom display cards are not workbook table exports.

Indexes are optional; AFM body-only contains its airflow row. Export Notes is optional and includes units, active log/purpose, pressure references, strategy and transfer guidance. Data starts at A1, numeric values remain numeric, text is not executed as formulas, axes are styled/frozen, and stored precision is retained. Workbook export does not replace project JSON or establish calibration safety. The lightweight controller uses a lazily loaded offline XLSX writer.

Verification: Edge availability/all/none/index/body downloads and unchanged calibration passed. Independent XLSX readback verified five sheets, numeric cells, Hondata gear orientation, body-only AFM and gear values. Excel desktop itself has not been tested. Existing v0.16 UAT remains pending; no new signoff inferred. Startup observation remains open.

UAT route: save your project; open v0.16.1 → Export Excel Workbook in the top header. (1) Choose Recommended, compare named units/statuses, and edit selections. (2) Select All Available: stale proposals stay disabled; Clear Selection disables Download Workbook. (3) Include row and column indexes + Export Notes → Download Workbook; open in Excel and confirm one table per selected sheet, numeric cells, exact source/proposal values, native orientation and metadata. (4) Repeat with indexes off: first body value at A1; AFM exports airflow only. (5) Make a proposal stale and reopen the exporter: refresh is required before it can be selected. Confirm unchanged calibration and save/reopen compatibility. For KTuner check each selected gear's sheet and atmospheric axis representation separately.
