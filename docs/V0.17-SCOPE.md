# v0.17 Datalog Navigation and Tuning Language

Approved by Jonny on 2026-10-02 after v0.16.2 acceptance (all 15 scenarios passed). Includes right-button drag range zoom, live left-button drag panning, click inspection/context menu, keyboard-accessible Pan Earlier/Pan Later/Zoom In/Full Datalog, page Collapse All/Expand All, saved section preferences, consistent EFI-oriented wording and mode-specific tuning summaries. Global player remains independent. Project format remains version 10; uiRelease is 0.17. No calculation changes or ECU actions.

Terminology: Datalog Review, Datalog Library, Datalog Playback, Datalogging Instructions; channel source replaces provenance, sample inclusion replaces eligibility, review range replaces evidence range, matching operating ranges replaces shared bins, and changes since review replaces revision signature. MPR, Boost Command, AFM, native pressure references/units and platform channel names retain their meanings. Internal identifiers remain compatible with old projects. Imported names, original channels, user notes and numeric/native calibration tables are preserved. Interface labels and dynamic text share one display glossary; the separate playback window and workbook labels are aligned too.

Guided adds the next tuning/review step. Standard uses a concise current setup. Advanced exposes calculation settings and sample-filter detail in the tuning summary. Existing contextual help and controls retain their mode behavior. Chart zoom/panning never changes sample filters or tuning calculations; boost proposals still use source tables and adjustment controls, while AFM corrections explicitly name the selected baseline datalog.

A startup race was corrected: the combined table-and-datalog loader now claims restoration before asynchronous legacy datalog-only loading can run between external scripts. This preserves cached calibration restoration. No startup speedup is claimed.

Deferred: new tuning algorithms, additional platforms/vehicles, pressure assumptions inferred from ambiguous channels, automatic ECU transfer, and unrelated backlog. All v0.17 UAT cases begin Not tested; prior v0.16.2 signoff stays accepted.
