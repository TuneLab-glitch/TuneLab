## Included

- Optional shared original/proposed value shading, zero-centered absolute/percentage differences, two palettes, no shading, gradient/numeric legends, stable scales with clipping counts and explicit reset.
- Boost shading compares absolute bar after source/output conversion. Airflow and gear use their displayed units. Source/unit/coordinate changes invalidate scales; manual refinements do not.
- Linked table rectangles and historical operating-location coverage for Boost/gear; positive interpolation weights only, original parsed row identity, gaps/out-of-axis handling, and explicit atmospheric-reference fallback.
- AFM evidence shows stored eligible baseline observations, local support versus the actual 50 Hz bin-center correction kernel. Display selection does not change correction or validation. Saved/manual proposals need fresh analysis provenance.
- Time/RPM/Hz evidence ranges, Shift-drag chart selection, keyboard/numeric range controls, complete histogram-bin selection, counts and reset. Plot zoom remains separate. Sample list shows the first 100; counts use all unique contributing samples. Chart markers are capped at 800 for display.
- Enhanced change review with changed/covered/uncovered counts, protected/manual status, stale proposals and missing validation; explicit revision inspection record and JSON report. Later value/evidence/rule changes invalidate inspection. No ECU application or outcome validation is implied.
- v0.8 JSON retains v0.3–v0.7 migration, shading settings/scales and review record. Transient evidence filters clear on reopen; calibration confirmations clear. v0.7 window handoff and separate panel arrangements remain.
