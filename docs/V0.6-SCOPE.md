# v0.6 approved scope

Approved by the user on 2026-10-02. v0.5 priority UAT was reported passed by the user; this does not establish that every original guide case was completed.

## Included

- Pointer rectangle selection, edge scrolling, Shift-click/Shift-arrow extension and visible protected selections, using the existing edit engine.
- Coordinated table zoom, readable fit-width minimum, horizontal scrolling and retained advanced sizing.
- Linked AFM original/proposed and delta inspection, actual g/s and percentage changes, changed-point markers and labeled magnification.
- Baseline and optional validation selectors with adjacent import/assignment and calibration context; validation never drives correction.
- Central Settings for terminology, complexity, appearance inheritance, airflow units, boost output default, preview behavior, review thresholds and browser storage.
- v0.6 workspace backups and v0.3–v0.5 migration, preflight validation, role/undo/layout/provenance retention and restore failure reporting.
- Per-file export mapping, unit provenance and explicit uncertain platform detection. Normalize time/boost for review and time/temperature/trim/known MAP units for AFM evidence. Preserve raw CSV. Real Hondata fixture tested privately; real KTuner verification pending receipt of a log.
- Status strip for platform terminology, active log/calibration, units and current/stale proposal.

## Deferred, still on backlog

Cross-table coordinated alignment; intentional gear-limit reasoning; advanced gradients/delta shading; personal reference attachments; searchable/versioned official knowledge index; optional AI/model management; evidence-based learning; expanded uncertainty summaries; independently imported platform calibration comparison; arbitrary-channel/calculated-field/playback viewer; linked range/bin selection and coverage heatmaps; gated guided workflow and beginner usability studies; verified factory-color themes and broader polish; dependency-aware structural undo; automatic AFM analysis; desktop installer.

Existing gear representation and comparison features are retained without new alignment rules. No live hardware, ECU flashing or full ECU simulator.

## Acceptance boundary

The build is ready for v0.6 UAT. Automated and headless Edge checks do not replace user acceptance in the destination tuning software. Unknown units and ambiguous channels are not inferred. AFM currently requires the v0.5 commanded-AFR and Fuel Status = 2 conventions; other status/mixture encodings are unsupported pending evidence. Native/unspecified MAP exports must be compatible before combining evidence.
