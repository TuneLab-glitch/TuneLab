# v0.18 Saved Table Restore and App Launch

Approved by Jonny on 2026-10-02 ("Do it"). The three-item scope is implemented: Adjusted Table / Tune Changes terminology, an Edge/Chrome app-mode launcher with a normal-browser fallback, and selective saved-project restore with a preview and scoped undo. Calculation engines and project version 10 are unchanged; uiRelease is 0.18.

Restore scopes: MPR Table, Boost Command Table, AFM Table, Boost By Gear Tables, or Boost Tables Tab (MPR plus Command only). A boost bundle includes source/adjusted values, axes, units, protections and its calculation controls. AFM includes source/adjusted native g/s values and protections; current datalog roles and filters stay, calibration confirmations clear, and saved adjusted values are manual rather than copied measurement confidence. Gear includes native/original/adjusted tables, their axes/units and saved gear reference/strategy controls; the shared pressure offset stays, and differing KTuner offsets block the preview. Unrelated datalogs, roles, layouts, project metadata and tables stay. Current protected boost/AFM coordinates cannot be removed or changed. Preview shows current and saved bundles before apply. Malformed controls, tables and unsupported files block without applying values. A changed selected table requires another preview. Undo Last Project Restore affects only that scope, permits unrelated edits, and blocks if restored tables were edited later. It is one-level and available until another restore, project load or window reload; Save Project remains the durable backup. Review acknowledgements are refreshed through the existing change-review system. Full arbitrary section/tab restore remains deferred.

Launch: extract the complete package and double-click Start-TuneLab.bat. The PowerShell helper selects an installed Edge/Chrome and passes the local file URL with --app; it does not create a private profile, install software or enforce kiosk restrictions. Open-TuneLab-in-Browser.bat uses the default browser. A saved browser workspace belongs to its browser profile and app folder: before moving from Codex's browser or another release folder, Save Project there and Open Project here. File import/export and popout/edit synchronization have browser regression coverage; native app-window appearance, device shortcuts and any browser-managed prompts need the launcher UAT on the user's computer.

Wording: Proposed Table → Adjusted Table; Proposed Changes → Tune Changes; Update All Proposals → Update All Adjusted Tables; Mark Current Proposals Reviewed → Mark Tune Changes Reviewed. Source Table, review/validation meanings, internal identifiers and old backups remain compatible. Imported filenames, original channels and user notes are protected from display translation. Workbook labels align with the app.

Jonny reports v0.17 UAT complete, but individual results/all-pass were not supplied; completion is recorded without inventing pass outcomes. v0.16.2 retains all fifteen accepted cases. All nine v0.18 cases start Not tested. No live ECU actions or private datalogs are included.
