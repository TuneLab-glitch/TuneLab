## Source applicability

[KTuner's toolbar documentation](https://ktuner.com/KTunerHelp/toolbar.htm) documents a CSV export action. [Hondata FlashPro datalogging documentation](https://www.hondata.com/help/flashpro/datalogging.htm) documents native `.fpdl` datalogs and frame behavior. Neither page establishes a universal CSV header/unit schema. Header aliases in this build are candidates requiring user review, not manufacturer-certified channel semantics. The supplied private CSV establishes its actual parse layout only; it does not validate arbitrary exports or ECU behavior.
