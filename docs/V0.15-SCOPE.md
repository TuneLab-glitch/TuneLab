# v0.15 Workspace Control and Guided Evidence Review

Jonny approved six items and then added a branching tutorial and careful destination-paste verification. v0.14 is accepted: eleven Pass in Edge. All v0.15 UAT remains pending.

Implemented: whole global-player Collapse/Expand with saved height/preferences and uninterrupted playback/tracing; dedicated global-playback-only controller window; chart time-range drag highlight/zoom with start/end field updates, context actions and keyboard-accessible Chart Actions; selection-anchored table wheel zoom using existing bounds; grouped review checkpoints retaining full edit operations; goal/intent/platform tutorial starting with exported logs; numeric destination paste-back comparison and explicit transfer checklist.

The main app owns the playback clock. The dedicated popout sends validated source/token/project/session commands and receives lightweight state, never the raw project or calibration editor. It does not acquire the editing lease. During an editing handoff to another workspace, playback commands are disabled with explanation until editing returns to main. Existing detached-table synchronization is retained. Repeated opening focuses the existing player; blocked popups explain fallback. Dock/close restores main controls without changing cursor. Main reload/disconnection disables the remote controller; some browsers close child windows when the opener closes. No disconnected controller continues playback independently.

Checkpoint grouping is a display/review layer over the unmodified journal: adjacent operations on the same workspace/kind with no gap over five minutes, or explicit Start New Review Checkpoint boundary. Exact-content approval records remain per operation. Adding an operation to an approved group makes it partially approved/needs review; there is no blanket inherited approval. All Checkpoints/Needs Review filter and full individual edit/undo history remain available. Suspected testing accumulation has not been proven; grouping does not erase test history or pretend it was inspected. History details populate on expansion to reduce unnecessary DOM volume.

Raw-chart drag zoom uses actual SVG transforms, a five-pixel click threshold, reverse drag and Escape/cancel. Time-based boost chart drag also updates the raw seconds fields; Shift-drag evidence selection remains separate. RPM charts are not misrepresented as seconds; their new time actions are unavailable. Chart Actions: Show Whole Recording, Zoom to Selected Range, Center on Playback, Copy Point Values. Reset keeps explicit bookmarked row restrictions with explanation. The pre-existing Show Whole Recording button can leave a bookmark. Wheel uses 75/100/125/150/200% existing steps, accumulates small trackpad deltas, anchors the selected cell or pointer cell, and lets Ctrl/Meta wheel retain browser zoom. Bound events are not swallowed. Custom live table zoom has optional validated preferences. No numeric edits occur from zoom.

Tutorial branches: AFM, Boost review/proposal, Startup diagnosis, AFM/Boost post-change validation; Hondata/KTuner/Other identifies export provenance, not assumed compatibility. Eight stages cover goal, existing-file import, channel/unit checks, calibration/review setup, evidence, proposal/findings, careful transfer and final project/save/validation plan. Ready checks and explicit acknowledgements prevent automatically confirming calibration, executing tuning actions or applying changes. Progress saves in project JSON and resets acknowledgements when the active recording changes. Relevant Logging Strategy instructions remain one click away. Startup branch makes no fueling proposal. Frequency AFM requirements are retained.

Transfer and Verify a Table lives in Change Review. Capture the current fresh Boost export, proposed AFM curve, or displayed gear table, then compare a table copied back from the destination program. Numeric axes/value mismatches, dimensions and stale references are reported; body-only mode explicitly cannot verify axes/origin. Comparison is against the rounded intended export; it does not silently tolerate altered values or transpose/shift data. Program-specific table selection, units, origin, backup/save and outside-app application require explicit user review. Numeric equality does not prove ECU table identity or safety. No hardware or flashing is performed.

Project schema 10/old migration remains. New optional revision15/tutorial15 metadata validates before restore. Transfer references are transient and must be recaptured after reopening. Original logs/backups are excluded from Git/deliverables. Full 333MB project performance, exact rounded KTuner screenshot axes, AI, independent platform calibration comparison and extra custom tabs remain deferred/unverified.
