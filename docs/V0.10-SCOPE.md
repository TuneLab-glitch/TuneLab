# v0.10 approved scope — 2026-10-02

Jonny approved all five proposed features and the interface cleanup. He added that every calibration table must remain available from previous project state without needing a log.

- Explicit purpose setup offers existing presets and RPM defaults; purpose, sample filters and calibration evidence roles stay distinct.
- Readiness identifies missing channels, empty measurements, unknown units, unreviewed mappings and malformed-width rows. Ready to review is not calibration confirmation or engine safety.
- Up to four selected raw channels plot on independent native-value axes with synchronized time/cursor and original-row inspection. Startup works without boost channels. Missing values/time gaps break lines; extrema-preserving display reduction retains raw inspection.
- Evidence bookmarks retain session identity, original row range, channels, time mapping/units, purpose, revision and observations. Reopen restores the range. Removed-log notes remain auditable. Project JSON and browser library retain bookmarks; invalid references in existing logs are rejected before loading.
- AFM validation compares independently eligible trim observations in 250 Hz bins, including the existing observation cap. Boost validation compares simultaneous actual-minus-command error in 500 RPM bins. Shared minimum support is explicit and one-sided bins show unavailable deltas. Both mappings/units and recorded revisions must be reviewed; the user confirms comparable conditions. No causal improvement or ECU simulation is claimed.
- Main import flow remains central; AFM role shortcuts use the same import function. The redundant Log review Open CSV button is hidden while its backup-compatible input remains. Purpose checklist connects to the driving/review guide.
- Review notes retain historical Learning entries; Pressure representations replaces the misleading Platform compare label. Current review status reflects the active purpose. Chart zoom is distinguished from eligibility and saved evidence ranges.
- Calibration tables, proposals and library are cached atomically in IndexedDB and restored independently of active-log selection. No gear table is invented when there is no prior imported table. Browser storage is optional/unreliable across origins; download JSON before upgrade or closing with unsaved work.
- Version 10 JSON retains versions 3–9 migration, explicit calibration gates, protected cells, edit history and shared-window recovery. Accepted v0.9.1 ZIP/sign-offs remain unchanged.

## Deliberate limits

Four raw plots and recorded-time playback support focused review; calculated channels, a complete advanced viewer and automatic channel semantics remain deferred. Comparison uses shared Hz/RPM bins, not automatic environmental/gear matching; the user must assess comparable conditions. No startup fueling proposals, automatic cross-table alignment, AI, attachments, hardware or flashing. Full Civic/KTuner semantics remain separately pending. The preexisting official-source applicability in Logging strategy is unchanged. v0.10 UAT is pending.

Cursor tracking and linked coverage counts have independent synchronized display toggles in Settings and table evidence panels, saved with visual review settings. Old backups default to visible. Hiding markers preserves selection/protection, filters, underlying evidence summaries and calculations.

## Additional approved review tools

Recorded-timestamp playback in the raw viewer: play/pause, first/last, one-sample steps and 0.25×–4× speeds. Playback respects the visible time/bookmark range, pauses at non-increasing timestamps and on log/range/workspace changes, and retains recorded gaps. No calculated channels/interpolation are added. Cursor tracking only marks eligible matching rows; skipped display frames remain available by stepping.

A My workspace custom workspace stores its name and live read-only table-view definitions in project JSON/browser workspace caching. Right-click or Add table opens an accessible insert chooser. Explicit original/proposed MPR and command views plus currently available app tables can be inserted. Existing resize, drag, keyboard move and left/right snapping apply. Open source opens the dedicated editor. This release supplies one custom tab; multiple custom tabs and inline duplicate editors remain deferred.
