# v0.13 Workspace and Playback Refinement

Jonny approved five scoped items on 2026-10-02: Command tracing repair, wider responsive grids, Active Log beside playback, Original Data Row gradients and obsolete-control cleanup. All v0.13 UAT scenarios remain pending. v0.12 retains eleven signed-off passes and one unresolved Command-tracing failure.

## Implemented
- Active Log reuses the existing library selector beside global Log Playback. Switching pauses, resets the cursor/range and refreshes trace/visits. Baseline/Validation assignments and calibration values are retained. The existing detached-window editing lease still applies.
- Command Pressure Units and a channel/unit/status explanation are visible beside playback. Explicit command-header units take priority over shared actual-boost units; per-recording reviewed overrides remain available. Unknown units are not guessed. Native, custom and detached views use the same trace state.
- Grid width expands to four half-panel tracks when the actual grid has at least 1800 CSS pixels available. Browser zoom-out increases available CSS width. Full panels occupy two tracks, allowing two full or four half panels side by side. Dragging shows the destination columns; Snap Left/Right and Alt+Left/Right work in wider grids. Saved optional column positions restore; narrow views ignore wide placement until space returns. Anchored controls stay anchored. Main width is no longer capped at 1900px.
- Original Data Row readings use independent per-channel whole-recording minimum/maximum and the selected table palette. Hover shows the numeric range. Constant channels use the midpoint and missing values stay uncolored. Color Original Data Row independently disables shading. Range statistics are cached per recording, not recomputed on every playback row.
- Remove orphaned advanced-option controls after their sections have moved; remaining controls identify the sections they reveal, reflect expansion and hide when Advanced experience already exposes everything. The redundant Si / Urban Gray preset is hidden/disabled, and old saved selections resolve to Civic Si 2026 Urban Gray Pearl through the vehicle catalog.
- Jonny's accepted default menu order remains intact. Project schema 10 is retained with optional validated v0.13 display metadata and optional grid columns.

## Command diagnosis and limits
The supplied saved project maps its active Command channel to BP CMD but leaves pressure units unset, with no unit-bearing header. A private diagnostic copy of the active recording's first 500 export lines produced 497 original numeric rows. Before an explicit unit choice, Command tracing was absent. An explicit PSI interpretation mapped all 497 sample rows to candidate cells. This reproduces the missing-units cause; it does not independently verify the physical units of that export. Jonny has been asked to confirm them. No pressure units are silently assigned to private logs.

The supplied full project is about 333 MB. Full-project browser verification was stopped after a prolonged transfer/load; private diagnosis used the reduced copy above. No claim of a full 333 MB performance pass is made. Original project/log files were not edited, copied into Git, or packaged. Wider-grid and row-color changes are presentation only. Visits/markers remain candidate recorded input locations, not proof of ECU control or tuning eligibility.

Exact KTuner screenshot axes still need a full-precision export. AI, automatic alignment, independent platform-calibration comparison, multiple custom tabs, installer, arbitrary calculated channels and hardware/flashing remain out of scope.
