# v0.14 Navigation, Playback and Review

Jonny approved this scope on 2026-10-02. All new UAT remains pending. v0.13 retains eleven accepted scenarios and one messaging presentation revision; functionality is not retroactively rejected.

Implemented: prominent labeled Command status and general notifications; SVG-coordinate chart click/drag and range selection; chart-local playback/hover readings; compact top log panel with pointer/keyboard height adjustment and project persistence; full-width position row; one-shot Go to Trace for native/custom table hosts; Ctrl+K navigation-only search; CSV/TXT drop zones beside playback and in Log Library; comma/tab datalog parsing retaining original text; exact-content Edit History approvals, batch approve/clear and read-only recorded-change navigation.

Approval scope is explicitly the project's recorded Edit History operations, not saved snapshots or current-proposal acknowledgement. The current-proposal review remains separate. Approval records store operation identity, exact before/after signature and time; no reviewer identity is fabricated. Later edits create separately reviewable operations. Changing an operation's content/undo status invalidates its approval. Go to Change shows saved before/after with per-coordinate current-cell navigation or changed-control links; structural frames are available read-only. It never restores a revision.

The log box defaults to natural compact height with a 260px maximum and internal scrolling when wrapping. User height is 170–800px. Resize handle arrows adjust by 20px; Home restores automatic sizing. Essential controls remain reachable through scrolling at narrow widths/zoom. Search lazily indexes current labels and adds MPR/Command aliases; selecting actions does not execute them. Unsupported text/native KDLG gives an explanation. CSV and tab-separated TXT use existing channel/header validation, missing-value rules and raw backup retention. Exact raw duplicates retain existing identity.

Go to Trace preserves playback position, zoom, selection and calibration values. It reveals candidate cells only when outside the visible viewport. Candidate cells remain recorded-input locations, not ECU influence or proof of safety. Point readouts preserve native raw-channel units (headers retained) and use PSI for normalized boost curves. Hover is temporary and does not seek playback. Full arbitrary-channel formulas, continuous auto-follow and chart comparison point matching remain deferred.

Prior private logs/projects are excluded. Exact KTuner rounded axes and full 333MB saved-project performance remain unverified. AI, independent platform calibrations, extra custom tabs, hardware and flashing remain deferred.
