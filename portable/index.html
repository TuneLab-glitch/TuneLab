Calibration context

Project JSON includes source curves, proposed tables, controls, protections, metadata and named snapshots. Raw CSVs and mapping profiles are embedded in project backups. Reopening clears calibration confirmations. Saving downloads a file. No background uploads or cloud storage.

How to start

  1. Choose a boost table or load a matching baseline CSV for AFM.
  2. Verify source units, channel names and calibration metadata.
  3. Set the desired adjustment and selection / blend controls.
  4. Calculate, inspect the curve and protected areas, then export.
  5. Use a separate validation log to compare the result.

This edition creates reviewable table proposals and analyzes logs. It does not connect to FlashPro / KTuner hardware or flash an ECU. The native Avalonia shell is retained in the source package.
