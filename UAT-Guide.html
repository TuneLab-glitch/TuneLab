TuneLab v0.5 — Historical-log UAT guide

Use your existing CSV logs and saved/pasted tables. No new drive, vehicle connection or flashing is required. This guide validates application behavior; it does not validate a calibration for vehicle use.

Prepare: Two or three historical CSVs, known table exports where available, and a disposable calibration for optional paste checks. Record unknown calibration names as unknown. Keep v0.4 available for comparison. Expected duration: 45–75 minutes; begin with LOG-01 to LOG-12, HELP-01, HIST-01 and SAVE-01.

For each case choose Pass, Fail, or Not tested and record actual behavior. Skipped cases are not passes. Browser resize, clipboard, file persistence and destination paste acceptance require your PC; automated DOM tests do not establish those outcomes.

SET-01 · Start and version

Steps: Extract the ZIP completely; launch Start-TuneLab.bat.

Expected: The browser opens TuneLab v0.5 without a missing-asset message. No server or vehicle connection is needed.

LOG-01 · Import several historical logs

Steps: Import two or more existing CSVs with Import logs once. Open Manage logs.

Expected: Each file appears once with row/channel counts. Record the calibration name only if known; unknown revisions remain unknown.

LOG-02 · Duplicate recognition

Steps: Import exactly the same CSV again, optionally under another filename.

Expected: The existing session is selected. No new session or import-learning entry is created. Exact file content determines duplication.

LOG-03 · Shared active session

Steps: Choose a log globally; visit Log review, Boost tables and AFM.

Expected: The active name remains visible. Log review uses it; table markers use the selected eligible sample where axes are available. AFM baseline is not silently confirmed.

LOG-04 · Assign AFM roles

Steps: Choose baseline and validation from the library selectors.

Expected: No reimport needed. Confirmations start unchecked. Only confirm when you actually know the installed table matches; otherwise test manual proposal mode.

LOG-05 · Useful filtering

Steps: In Log review compare Whole drive / RPM selection with Loaded acceleration, then AFM-eligible samples if required channels exist.

Expected: Counts and exclusion reasons change. All related plots use eligible samples. Missing required channels produce an explicit error, not fabricated zeros.

LOG-06 · Select a historical segment

Steps: Choose a detected segment or click its summary row.

Expected: The selected segment is isolated. Candidate segments use pedal/command, continuity and gear boundaries; inspect whether it is the pull you intended.

LOG-07 · Slider, markers and error

Steps: Move the row slider through a segment, then click and drag the chart.

Expected: Cursor, visible point markers, timestamp, RPM, command, actual and simultaneous error change together. Error equals actual minus command at that sample.

LOG-08 · Excluded gaps

Steps: Choose All eligible segments where a drive has excluded cruise / shifts or sampling gaps.

Expected: Separate segments are not connected with a misleading line. Tiny isolated points may not create a visible line segment.

LOG-09 · Zoom and manual axes

Steps: Zoom around selection; set time and Y bounds; reset. Move the slider outside a narrow time range.

Expected: Range changes visibly. Slider brings its selected sample into the configured time window. Reset restores automatic bounds. Invalid bounds give an explanation.

LOG-10 · Colors and visibility

Steps: Change actual/command colors and disable/re-enable each channel.

Expected: Plot updates. With both disabled, a clear empty message appears. Numerical analysis is not changed by color/visibility.

LOG-11 · Histogram and scatter

Steps: Inspect error histogram and RPM/error scatter; click a bar or scatter point.

Expected: A scatter point moves inspection to its source sample. A histogram bar reports count/range and moves to its first contributing sample; it does not select every contributor.

LOG-12 · Historical comparison

Steps: Choose another historical log and an eligible comparison segment. Toggle time/RPM X-axis.

Expected: Dashed purple actual-boost comparison appears. Time comparison aligns segment starts; it is not wall-clock alignment. Check gear, fuel and temperatures separately before drawing conclusions.

HELP-01 · Contextual page help

Steps: Open Help & terminology in Log review, AFM, Boost by gear and Edit history.

Expected: Purpose and instructions differ by page. Official sources are clickable, with platform/applicability caveats. Links require Internet; explanations are local.

GUIDE-01 · Guided workflow

Steps: Set Guided and click the numbered steps in boost, AFM and logs.

Expected: Each step explains the next action and highlights/focuses its control. Steps are navigational aids, not proof that the preceding step has been validated.

GUIDE-02 · Advanced discoverability

Steps: In Guided/Standard use the page Show advanced options button; hide again; then choose Advanced.

Expected: The local button has explicit show/hide text. Advanced reveals advanced sections. Data and proposals survive mode changes.

EDIT-01 · AFM final preview

Steps: Start manual AFM proposal or analyze a matching historical baseline. Inspect the two-row preview; edit a positive unprotected cell.

Expected: Only column one carries labels. Proposed value and curve update. Copy preview and exported numeric output agree at chosen precision.

EDIT-02 · Manual operations and protection

Steps: Select a rectangle; try add, set, percent, interpolation and smoothing. Protect a source cell and regenerate/edit its proposal.

Expected: Operations respect selection and protection. Interpolation preserves endpoints; smoothing preserves boundaries. Percent operates on displayed values.

SOURCE-01 · Edit and restore source

Steps: Double-click a boost source cell and change a value. Restore entire last import.

Expected: Source change invalidates the proposal; restoration recovers imported values/dimensions. Single click still toggles protection.

SOURCE-02 · Resample an internal breakpoint

Steps: Add an RPM breakpoint inside the existing range in Edit source values & indices; preview then apply.

Expected: Preview does not mutate source. Apply interpolates using axis spacing. Repeated native MPR columns remain distinct when their axis is unchanged.

SOURCE-03 · Invalid/protected regrid

Steps: Try a new RPM outside the source range; then a grid removing a protected coordinate.

Expected: Both are blocked. Releasing protection requires an explicit user action. A changed duplicate MPR axis is blocked rather than guessed.

SOURCE-04 · Import different dimensions

Steps: Paste a valid complete table with a different size; confirm no locked coordinate is removed.

Expected: Supplied values are imported exactly. No interpolation replaces complete imported values. Last-import restoration uses this successful import; a failed import does not change it.

HIST-01 · Locate edits

Steps: Generate a proposal, make two manual edits, then open Edit history. Use Show in table.

Expected: Page/table/date and coordinates are visible. It navigates to the relevant page and first affected cell when a cellwise delta exists.

HIST-02 · Selective undo

Steps: Make edit A to one cell, then edit B to a different cell. Undo A only. Repeat with B overlapping A.

Expected: Disjoint undo retains B. Overlap is blocked with an explanation. Structural/unit/control changes use revision restoration instead.

HIST-03 · Restore revision

Steps: Restore state after an earlier edit and review history.

Expected: Earlier editing state returns. Restoration is a new journal entry; later history remains inspectable. Recheck calibration/session match afterward.

REVIEW-01 · Review thresholds

Steps: Create a deliberate large proposal; open advanced warning settings and change thresholds.

Expected: Alerts update, with coordinates and measured differences. Rules are preferences, not engine limits. Export review includes all alerts.

PLAT-01 · Names and representations

Steps: Toggle Platform terminology; open Platform compare and choose either pressure table.

Expected: Full names/reference titles change while source provenance remains. Comparison shows bar and matching PSI without changing source or claiming equivalent ECU behavior.

GEAR-01 · Native and derived gear views

Steps: Use an actual gear table or explicitly synthetic demo; toggle Hondata/KTuner format and atmospheric strategy.

Expected: Native original remains recoverable. Hondata is Gear × RPM; KTuner is per-gear RPM × PA. Translation assumptions and information loss are stated.

UNIT-01 · Preserve physical proposal

Steps: Change boost output bar → kPa → PSI → bar; change airflow g/s → kg/h → g/s.

Expected: Underlying physical values return within displayed rounding. Unit changes do not silently erase manual edits. Confirm destination expects the selected units.

LAYOUT-01 · Global and page themes

Steps: Apply a global theme, choose This page only and override another page; move between pages and reset.

Expected: Each page inherits app defaults or shows its override. Reset removes its override. Theme colors remain readable.

LAYOUT-02 · Resize and scaling

Steps: Drag panel/table corners; collapse, expand and restore. Change cell/header fonts and padding; try column fit modes.

Expected: Usable resize handles, readable cells and frozen indices. Layout changes do not alter table values or exported precision. Verify at your laptop display scaling.

LEARN-01 · Transparent observations

Steps: Record an analysis insight; exclude/reinclude a session; remove a disposable session.

Expected: Evidence/limitations and eligibility actions are auditable. Confidence is not inflated by file count. Removed sessions are labeled in their retained entries.

SAVE-01 · Complete project round trip

Steps: Save project JSON. Close/reopen app and load the JSON; inspect multiple logs, proposals, journal, metadata and preferences.

Expected: Raw CSVs and session IDs survive; no reimport required. Baseline/validation confirmations are cleared. Browser storage is optional; JSON is the portable backup.

EXPORT-01 · Paste acceptance offline

Steps: Copy/export a proposal into a disposable calibration in Hondata/KTuner; copy it back for comparison. Do not upload to the vehicle.

Expected: Axes, dimensions, units, labels and rounded values agree. If not, stop using that export route and report before/after values.

Reporting a defect

Include case ID, page/table, exact steps, selected units/filter, historical log name, expected versus actual values, and a screenshot if useful. Severity: Critical = wrong values or lost data; Major = blocked workflow; Minor = presentation or explanation issue. Keep the original files so failures can be reproduced.

Release boundaries

AI, outcome prediction, automatic confidence learning, full arbitrary calculated-channel editing, a factory-color catalog and complete ECU simulation are not included. Learning entries are transparent observations. Platform compare is a representation view; gear conversion is the supported structural translator. Automatic preview pauses when manual refinements would be replaced.
